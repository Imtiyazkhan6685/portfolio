# ImtiyazPortfolio

A minimalist portfolio for Imtiyaz Khan (Python Developer | AI & Machine Learning) built with a dark developer aesthetic inspired by [jayjr.vercel.app](https://jayjr.vercel.app/).

## Features
- **Canvas Cursor Follower**: Exact multi-trail spring-dampened cursor ribbon wave.
- **Aceternity UI Canvas Reveal Effect**: Ambient square pixel grid background with subtle periodic on/off pulsing and bottom fade gradient.
- **3D Flipping Avatar**: Interactive 3D flip card between portrait and animated avatar.
- **Widescreen 16:9 Project Cards**: Clean project showcases with punchy descriptions and vector architecture diagrams.
- **Technical Deep Dives**: Detailed technical narratives on BERT NLP Sentiment Analysis and Housing Price Prediction Flask REST API with interactive reading modals.
- **Interactive Resume Modal**: Built-in silky smooth zoomable resume document viewer and direct PDF download.
- **Dark / Light Theme Toggle**: Seamless persistence via localStorage.
